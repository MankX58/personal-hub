# Hub personal

Next.js 16 + Tailwind 4. Tareas diarias + rutina PPL/UL con registro de pesos y estadísticas.

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # lógica de cambio de día / rachas
```

Los datos se guardan en el navegador (localStorage). Usa Ajustes → Exportar/Importar para copias o pasar al móvil.
En el móvil: "Añadir a pantalla de inicio" para usarla como app.
